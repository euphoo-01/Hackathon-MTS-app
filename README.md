# Приложение Healarm
### Приложение создано на Space Hackathon with MTC
Представьте человека, которому только недавно сделали хирургическую операцию и он восстанавливается после нее. Приложение Healarm предусматривает отслеживание жизненно важных показателей пациента. Главная особенность нашего приложения – отслеживание положения тела с помощью NB-IoT устройства. Если человек вдруг перевернулся, упал и не может позвать на помощь, то NB-IoT датчик посылает сигнал на устройство медицинского работника. Так же предусмотрен такой же функционал для опекунов пожилых людей или опекунов детей с ограниченными возможностями.
